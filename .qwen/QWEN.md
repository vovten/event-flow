# Qwen Manifest — Правила проекта

## Запуск тестов
**Всегда запускать тесты вместе с checkstyle:**
```bash
mvn test
```

Не использовать флаги пропуска checkstyle (`-Dcheckstyle.skip=true`). Checkstyle является обязательной частью процесса сборки.

## Примечание
Для работы checkstyle требуется Java 11+. Убедитесь, что используется совместимая версия JDK.
